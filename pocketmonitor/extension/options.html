PocketMonitor Browser Link

Lets the PocketMonitor app on this computer show your own open tabs on your own phone.

1. Paste the key

In the PocketMonitor app → Browser activity → “Install the browser extension” → Copy key.

2. Choose what is shared
Exactly what is sent
  • Tab title (optional) and website domain, e.g. github.com
  • Which tab is active, pinned or playing audio
Never sent: page content, full web addresses, passwords, form data, keystrokes, browsing history, or anything from private/incognito windows (this extension is not allowed to run there). Data goes only to 127.0.0.1 on this computer.
